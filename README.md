Build a Linear Regression Model using Scikit-learn
Overview

This project demonstrates how to build and train a Linear Regression model using Scikit-learn. The dataset is loaded from a CSV file, split into training and testing sets, and used to train the model for predicting the target variable.

Technologies Used
Python
Pandas
NumPy
Scikit-learn
Steps Performed
Imported the required libraries.
Loaded the dataset from a CSV file.
Selected features and target variable.
Split the dataset into training and testing sets.
Created a Linear Regression model.
Trained the model using the training dataset.
Generated predictions on the test data.
